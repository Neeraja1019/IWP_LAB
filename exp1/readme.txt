Experiment 1 — Personal Webpage
Aim

To design and develop a professional and responsive personal webpage using HTML5, CSS3, and Bootstrap.

Technologies Used
HTML5
CSS3
Bootstrap 5
Description

This experiment demonstrates the development of a personal profile webpage using HTML and CSS. Bootstrap is used to create a responsive and attractive user interface.

The webpage presents personal information, hobbies, technical skills, and multimedia content in a structured and professional layout.

Features
Personal profile section
Profile picture
Personal details table
Hobbies list
Technical skills list
Audio player
Video player
Responsive design
Professional user interface
Bootstrap styling
File Structure
exp1/
│
├── my.html
├── sample.mp3
└── sample.mp4

How to Run
Open the exp1 folder in Visual Studio Code.
Open my.html.
Right-click on the file.
Select Open with Live Server.
The webpage will open in the browser.

Alternatively, my.html can be opened directly in a web browser.

Expected Output

The webpage displays a professional personal profile containing:

Profile picture
Name and designation
Personal information
Hobbies
Technical skills
Favorite music
Favorite video
Learning Outcome

This experiment helps in understanding:

HTML webpage structure
CSS styling
Bootstrap framework
HTML tables
Ordered and unordered lists
Audio and video elements
Responsive webpage design
Conclusion

The experiment successfully demonstrates the creation of a responsive and professional personal webpage using HTML, CSS, and Bootstrap.
