Experiment 3 — Registration Form with JavaScript Validation
Aim

To design a professional registration form using HTML and CSS and validate the user input using JavaScript.

Technologies Used
HTML5
CSS3
JavaScript
Description

This experiment demonstrates the creation of a modern registration form with client-side form validation using JavaScript.

The form collects the user's name, email address, phone number, and password. JavaScript is used to check whether the entered information satisfies the required validation rules before registration is completed.

Features
Professional registration interface
Full name input
Email address input
Phone number input
Password input
Terms and conditions checkbox
JavaScript form validation
Email format validation
10-digit phone number validation
Minimum 6-character password validation
Registration success message
Responsive design
Modern gradient UI
Interactive input fields and buttons
Validation Rules

The following validations are performed:

Name cannot be empty.
Email must be in a valid format.
Phone number must contain exactly 10 digits.
Password must contain at least 6 characters.
Terms and conditions must be accepted.
File Structure
exp3/
│
├── registration.html
└── README.md

How to Run
Open the experiment folder in Visual Studio Code.
Open registration.html.
Right-click the file.
Select Open with Live Server.
The registration page will open in the browser.

The file can also be opened directly using any modern web browser.

Expected Output

A professional registration page is displayed with a modern two-panel design.

The user can enter:

Full Name
Email Address
Phone Number
Password

After clicking Create My Account, JavaScript validates the entered information and displays the appropriate validation message.

If all information is valid, a Registration Successful! message is displayed.

Learning Outcome

This experiment helps in understanding:

HTML forms
Form input elements
CSS styling
Responsive web design

Form validation

Client-side validation
Conclusion

The experiment successfully demonstrates how HTML, CSS, and JavaScript can be combined to create a professional registration form with effective client-side validation.
